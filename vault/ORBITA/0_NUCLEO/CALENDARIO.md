# CALENDARIO
*Fuente única del horario. La vista Calendario de Obsidian se dibuja con esta tabla, con [[CITAS]], con [[SESIONES]] y con las tareas con hora de cada nota del día.*

**Días:** L, M, X, J, V, S, D. Se pueden juntar: `L-V` o `L,M,J`.
**Órbita:** dinero, cuerpo, mente, relaciones, estudios o nucleo.
